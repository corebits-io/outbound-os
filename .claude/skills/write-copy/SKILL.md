# Write copy

Write email #1 that earns a reply — specific, short, human.

**Read:** the prospect's `research/<domain>.md`, `03-value-prop-and-messaging.md`, `winning-emails.md`, **`knowledge-base/my-voice.md`** (the operator's proven voice — match it), and **`knowledge-base/copywriting.md`** (the frameworks + the anti-AI rubric).

## Process — draft → critique → rewrite (don't skip the critique)
1. **Find the trigger.** Pull the ONE specific, true observation from research (the email's first line). If there isn't a specific one, go back to research — **do not write generic.**
2. **Draft 2 short variants** using Josh Braun's 4-T (trigger → problem → question), in the voice from `winning-emails.md`.
3. **Critique** each against the anti-AI rubric in `copywriting.md` (specific line 1? under ~75 words? one question not a CTA? more "you" than "I"? problem-first? no banned phrases / AI rhythm?).
4. **Rewrite** the best into the final — cut anything that fails the rubric.

**Write:** the final opener; list personalization fields in `sequences/custom-fields.md`.

## Hard rules
- **Under ~75 words** (aim 25–50). A **question**, not a CTA. One idea, one ask.
- Lead with the specific trigger — never `{{first_name}}` alone.
- **No fabricated results/claims.** No banned phrases (see `copywriting.md`).
- If it could be sent to 1,000 companies unchanged, it's wrong — rewrite.
