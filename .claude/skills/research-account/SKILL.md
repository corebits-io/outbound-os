# Research account

Per-account intel + cross-account patterns so copy is built on evidence.

**Read:** the active campaign's `accounts.csv`, `prospects.csv`, and the brain files.
**Write:** `campaigns/<campaign>/research/<domain>.md` (5–8 bullets, cite sources) + `research/_patterns.md`; set carried-forward prospects to status `researched`.

## Steps (full detail in `playbooks/03-research-and-patterns.md`)
1. Per account: what they do, intent/timing signals, one specific true observation, the problem hypothesis.
2. Across the list: recurring problems, shared language, segments worth splitting.

**Rule:** only verifiable facts; mark uncertain as `likely`/`guess`. Don't over-research low-fit accounts.
