# _EXAMPLE — a fully worked sample campaign

This is a **complete, finished campaign you can read end to end** to see what "good" looks like before you run your own. Everything here is **fictional** — the company selling ("Cohort"), every target account, and every person are invented for the demo. No real data, no real emails, no real keys.

**The fictional offer:** *Cohort* — a customer-onboarding platform for B2B SaaS that gets new users to first value faster and cuts early churn.

Read it in this order — it mirrors the 7 stages:

1. **The brain** — `01-offer-and-icp.md`, `02-personas.md`, `03-value-prop-and-messaging.md`, `04-fit-examples.md`
2. **Sourced + qualified accounts** — `accounts/accounts.csv`
3. **Chosen person per account** — `prospects/prospects.csv` (note the `why_this_person` and the `verified`/`likely`/`guess` tags)
4. **Research** — `research/<domain>.md` notes + `research/_patterns.md`
5. **The sequence** — `sequences/sequence-scaling-cs.md` + `sequences/custom-fields.md`
6. **The log + a performance snapshot** — `reports/log.md`, `reports/2026-06-15-performance.md`

> **Note:** for brevity this sample shows **3 representative research notes** (not all 14 accounts) and **one fully-built segment** (`sequence-scaling-cs.md`). A real campaign researches every carried-forward account and builds a sequence per segment — the segments are identified in `research/_patterns.md`.

To start your own, don't edit this folder — copy `campaigns/_TEMPLATE` to a new campaign and fill it in (the onboarding prompt does this with you).
